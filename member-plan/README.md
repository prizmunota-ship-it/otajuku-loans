# 太田塾メンバー行動予定表（雛形）

公開パス: `/member-plan/`。太田専用 `/keikaku/` と独立。
外部API・Supabase・総合収支を利用せず、ブラウザの localStorage
`otajuku-member-plan-prototype-v1` のみに入力値を保存する。
架空サンプル以外の会員・太田個人データを配布ファイルへ含めない。

## 計算
- 基準は開始月の月初預金。12か月の月末残高を計算。
- 家賃−元利返済−運営費＋その他収入−生活費＋単発調達−単発支出−購入自己資金。
- 購入金額は説明用。融資総額を入金加算せず、購入自己資金のみ一度控除。
- 取得戸数は決済月に加算。家賃・返済・運営費は指定した収支開始月以降に加算。
- 運転資金等の借入は入金月に加算、返済は指定月から継続。
- 含める/外すで比較。月内の支払順・ローン終了・売却・税務計算は未対応。
- 基準月を進める際、既に現在地へ取り込んだ購入・調達を除外して二重計上を防ぐ。
- 金額は万円、内部小数4桁、画面は小数1桁。
