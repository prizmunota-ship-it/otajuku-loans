# 太田塾メンバー行動予定表（簡易版）

公開パス `/member-plan/`。太田専用 `/keikaku/` と独立。
2026-11-05本人訂正：元Excel（20260701.xlsx）と太田用の見せ方に統一。

- 毎年1月〜12月。前年/翌年ボタン。金融機関・直近メモ・12か月・備考。
- 下段7行：戸数、年間満室賃料、年間満室CF、借入調達、賃収その他、支出、預金。
- 最低預金設定・警告・上部集計カード・月額返済/運営費/生活費などの入力は廃止。
- 最初の入力は基準月・預金・戸数・年間賃料・年間CFの5項目。目標は自由記述。
- 融資相談セルは価格/自己資金のみ表示。戸数/年額は任意で詳細を開く。
- 取得月初期値は相談翌月。自己資金は取得月の支出、戸数/年額も取得月から加算。
- 預金＝基準預金＋基準月以降の入力済み調達−支出。年賃料/CFは自動入金しない。
- 数値セルの手入力は差額を保存。調達/支出は当月・未来預金に累積反映。
- 基準月より前の戸数/年額/預金は未登録表示。現在地に取り込んだ過去の購入は再加算しない。

ログイン/同期なし。localStorage `otajuku-member-plan-prototype-v2` のみへ保存。
v1の保存がある場合は年額へ換算し予定を引き継ぐ。v1キーは削除・上書きしない。
旧版の月額収支の自動繰越は廃止。入金予定は賃収その他へ入力する。
JSON書出し/読込（v1も移行対応）。実データは外部送信なし。
本提供前には会員認証とユーザー別保存を別途追加する。
テスト: `node --test tests/member-plan.test.mjs`。
